# Mighty Knights — "planned planthood"

Mighty Knights ("planned planthood") is a group project (grupparbete) that implements a small static web experience built with HTML, CSS and a bit of JavaScript.
A quick glance at the repository languages:
- CSS: 67.5%
- HTML: 29.4%
- JavaScript: 3.1%

## About
This repository contains the front-end for the Mighty Knights project created as a group assignment. The goal was to practice HTML/CSS layout and responsive design.

## Demo
Open `index.html` in your browser to view the site. If you'd like to serve it from a local development server, see the instructions below.

## Features
- Responsive layout that adapts to different screen sizes
- Styled pages with custom CSS and visual assets
- Minimal JavaScript for interactivity and UI enhancements
- Clean, semantic HTML structure to support accessibility

## Technologies
- HTML5
- CSS3 (the majority of the project)
- JavaScript (small interactive pieces)
